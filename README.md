# SPIRA CLIENT

**An independent Minecraft: Java Edition launcher for Windows.**

SPIRA CLIENT is a desktop launcher project focused on providing a clean, convenient and customizable way to manage Minecraft installations, profiles and game resources.

## Purpose

The goal of SPIRA CLIENT is to make launching and managing Minecraft easier through a desktop application with an intuitive interface, profile management and access to community-created content.

The project is independently developed and is currently in active development.

## Planned Features

- **Minecraft Profiles:** Create, manage and organize separate game profiles and versions.
- **Minecraft Launching:** Install and launch supported Minecraft: Java Edition versions.
- **Microsoft Authentication:** Sign in through the official Microsoft authentication flow and verify Minecraft account access.
- **Player Skins:** Display the authenticated player's Minecraft profile and official skin.
- **Modrinth Integration:** Browse supported mods, resource packs and shaders through the Modrinth platform.
- **Installation Management:** Configure game versions, loaders and separate game directories.
- **Settings:** Customize launcher preferences and supported game settings.
- **Screenshots:** Access screenshots associated with supported Minecraft installations.

Features are being developed incrementally. Not all planned features are currently available.

## Authentication and Security

SPIRA CLIENT is intended for legitimate Minecraft: Java Edition users.

The project aims to use official authentication and ownership verification mechanisms. It does not intend to bypass Minecraft ownership requirements or reuse credentials belonging to other applications.

Microsoft passwords will not be requested directly by the launcher. Authentication will use an appropriate supported sign-in flow.

## Project Status

SPIRA CLIENT is an early-stage project. The launcher interface and foundation are being developed, followed by profile management, authentication, game installation and other integrations.

The implementation and availability of individual features may change as development progresses.
